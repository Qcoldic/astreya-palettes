# Гаммы Астреи

Витрина цветовых решений для мини-аппа Telegram-бота «Астрея».

Пятьсот цветовых сочетаний главного экрана: 250 тёмных и 250 светлых.
Каждое проверено расчётом контраста по двенадцати парам (WCAG), у каждого свой номер.

## Что умеет страница

- **Нумерация** — у каждой гаммы номер от №1 до №500.
- **Отметки** — звёздочка на карточке, список понравившихся собирается внизу и переживает перезагрузку.
- **Независимая нижняя панель** — красится отдельно от экрана, переключателем «Крашу экран / Крашу панель».
- **Фильтры** — тёмные, светлые, пятнадцать оттенков белого.
- **Поиск по номеру** — ввести номер и попасть сразу на нужную гамму.

Карта на экране построена на демонстрационных данных: геометрия колеса настоящая,
долготы планет взяты для показа.

## Сборка

Страница собирается из частей в один самодостаточный файл:

```
python build/assemble.py
```

Результат — `docs/index.html`. Публикуется через GitHub Pages из папки `/docs`.
